# Contributing to ORVION

We're building the settlement layer for autonomous agents. Join us!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch
4. Make your changes
5. Submit a pull request

## Development Setup

```bash
npm install
npm run docker:up
npm test
```

## Code Standards

- Use ESM modules
- Add error handling
- Include tests
- Document complex logic
- Follow existing patterns

## Reporting Issues

- Use GitHub Issues
- Include reproduction steps
- Provide environment details

## Feature Requests

- Discuss in Issues first
- Reference the Roadmap
- Explain use case

## Community

- Join our Discord
- Follow on Twitter
- Star the repo ⭐

---

**Every contribution matters. Let's build the future together.**
