# Submission Checklist

Esta checklist resume a trilha para transformar o repositório em uma submissão pública forte, limpa e convincente.

| Bloco | Status desejado |
| --- | --- |
| Repositório | Público, bonito, documentado e sem segredos |
| Demo | Fluxo 402 -> pay -> retry funcionando |
| Métricas | 50+ chamadas pagas registradas |
| Circle/Arc | Ao menos uma transação real validável |
| Vídeo | 4 a 5 minutos com narrativa clara |
| Slides | Tese, arquitetura, pricing, demo e roadmap |

## Ordem recomendada

Primeiro, estabilize a base técnica. Em seguida, conecte pagamento real. Depois, registre métricas, grave vídeo, consolide slides e valide toda a trilha pública do projeto antes da submissão.
